Dual AI Cross-Arbitration Engine

High explainability without cloud dependence. Every acoustic window is independently classified by two distinct architectures.

Python Feature Engine

Extracts 40 MFCCs, Spectral Centroid, Bandwidth, Roll-off (85%), Zero-Crossing Rate, and RMS frame energy. Classifies vectors through trained Scikit-Learn acoustic models with >90% accuracy.

Google Teachable Machine

Independent 10-class neural network trained on 128-band Mel-Spectrogram frames. Evaluates 2D frequency distribution patterns without communicating with the Python model.
